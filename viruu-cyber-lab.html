03 / Learn

Tutorial roadmap

Follow this order to build strong foundations before advanced security topics.

STEP 01

Python fundamentals

Variables, data types, conditions, loops, functions, lists, and small utilities.

STEP 02

Web & software basics

HTML, CSS, JavaScript, Git, GitHub, debugging, and writing clear project documentation.

STEP 03

Networks & Linux

Learn IP addresses, DNS, HTTP/HTTPS, permissions, command-line navigation, and logs.

STEP 04

Defensive cybersecurity

Authentication, MFA, updates, backups, phishing awareness, encryption, and threat modelling.

STEP 05

Authorized lab practice

Use deliberately vulnerable training apps or your own isolated test environment. Get explicit permission before testing any system.
